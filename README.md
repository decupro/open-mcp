# Open MCP

MCP Server plugin enabling LLM connections to your WordPress. Free and open source: connect Claude, ChatGPT, Cursor, VS Code or any MCP client and manage your whole site — content, media, users, comments, menus, plugins, themes, templates, styles, settings and every REST route.

- Streamable HTTP endpoint: `/wp-json/open-mcp/v1/mcp`
- OAuth 2.1 (dynamic client registration + PKCE) for one-click Claude connectors, plus API keys and Application Passwords
- 71 built-in tools + automatic bridge for the WordPress Abilities API (6.9+)
- Per-tool toggles, read-only mode, role gating, activity log
